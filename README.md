## About Awad Nahas App

Awad Nahas is a state-of-the-art e-commerce application designed using Flutter v.3 and adheres to Clean Architecture with a feature-first approach. Our application offers seamless e-commerce experiences with multiple payment options, including Tamara and Payfort, ensuring both flexibility and security for our users.

## Features
- Clean Architecture (feature-first approach)
- Multiple payment methods (Tamara, Payfort, etc.)
- Unit testing integrated within the Clean Architecture
- Cross-platform compatibility thanks to Flutter v.3
- Easy to navigate UI/UX

## Getting Started

### Prerequisites
- Flutter v.3 installed on your development machine.
- An understanding of Clean Architecture and how to structure features first.
- Familiarity with payment gateways like Tamara and Payfort.

### Installation

1. Clone the repository to your local machine using `git clone https://github.com/Hossamattia028/awad_nahas.git`
2. Navigate to the project directory `cd awad_nahas_production`
3. Run `flutter pub get` to install all the dependencies.
4. Start the app by `flutter run`
